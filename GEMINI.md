# Workspace Summary: Waybar & Hyprland Dotfiles

This directory (`~/.config/waybar`) serves as the central hub for a highly customized Linux desktop environment built on **Hyprland** and **Waybar**. It follows a "dotfiles" pattern, managed by an `install.sh` script that symlinks configurations to their respective locations in `~/.config/`.

## 🏗️ Core Architecture
The setup is modular, with Waybar acting as the primary status and interaction layer. Most Waybar modules are backed by custom Python and Bash scripts that provide both status information and interactive GTK-based popups.

### Key Components:
- **Window Manager**: [Hyprland](hyprland.conf) (Configured in `hypr/`).
- **Status Bar**: [Waybar](config.jsonc) (With a unique 3D aesthetic defined in `style.css`).
- **Application Launcher**: [Walker](walker/config.toml).
- **Terminals**: [Ghostty](Ghostty/) and [Kitty](kitty.conf).
- **Shell Prompt**: [Starship](starship.toml).
- **Power Menu**: [Wlogout](wlogout/).
- **Editor**: [Neovim](nvim/) (LazyVim-based setup).

## 🚀 Waybar Modules & Scripts
The Waybar configuration (`config.jsonc`) is divided into three logical sections:

### Left Section (Action & Connectivity)
- **Media**: `media_info.py` - Displays current track and provides player controls.
- **Updates**: `system-update.sh` - Checks for package updates and launches a terminal for installation.
- **Taskbar**: An expandable drawer containing `custom/apps` (`apps.py`) and standard window icons.
- **Volume**: `volume_manager.py` - A sophisticated volume controller with scroll support and mute toggle.
- **Network/Bluetooth**: `wifi.py` - Manages wireless connections with a custom UI.

### Center Section (Navigation)
- **Workspaces**: Uses **Hindi (Devanagari) numerals** (१, २, ३...) for workspace identification, providing a unique cultural aesthetic.

### Right Section (System Status)
- **System Stats**: `sys_stat.py` - Provides a popup with detailed CPU/RAM/Temp information.
- **Clipboard**: Integration with `cliphist` and `walker` for history management.
- **Clock**: `calendar_time.py` - Interactive clock with a calendar popup.
- **Power**: Quick access to the `wlogout` menu.

## 🎨 Visual Identity
- **3D Aesthetic**: The `style.css` uses heavy box-shadows and margin transitions to create a "tactile" 3D button effect for bar modules.
- **Dynamic Theming**: Integrated with `pywal` (implied by `current-theme.sh` and CSS variables) to match the system colors to the current wallpaper.

## 🛠️ Management Scripts
- `install.sh`: Automatically symlinks the repository contents to `~/.config/`.
- `wallpaper_switcher.sh`: Handles background changes.
- `menu_fix.sh`: A utility script for menu adjustments.
